One row per image. The caption ladder is a dot strip on the row, not a labelled child per rung under a chevron — three rows per image spent the sidebar's whole vertical budget on a fact three pixels carry, and each dot is still the button that opens that version in the panel.
Both modes draw the same rows: group view joins the grouping manifest's rels onto the one listing, so a filter and a truncation mean one thing, and whatever no component claims falls into ungrouped — switching modes cannot lose an image.
Rows never wrap — the tree is scanned by the thousand. Selection is two signals (a fill and a 3px inset accent bar) so it survives beside a hover, which is only #ffffff08.
